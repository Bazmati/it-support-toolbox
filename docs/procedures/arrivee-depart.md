Procédure : arrivée / départ d'un collaborateur

Arrivée (J-5 avant le 1er jour)





Créer le compte AD selon la convention prenom.nom



Ajouter aux groupes du service (partages, imprimantes)



Préparer le poste : image standard, intégration au domaine, vérifier les mises à jour



Configurer la messagerie + signature + licences (Microsoft 365)



Test complet avant remise, prévoir la procédure de premier changement de mot de passe

Départ (le jour même)





Sauvegarder les données personnelles de l'utilisateur (selon la procédure RH)



Récupérer le matériel (poste, badge, téléphone, clés)



Désactiver le compte AD (jamais supprimer avant la période de rétention)



Retirer des groupes, révoquer VPN/accès distants, transférer la messagerie selon consignes RH



Cocher la case dans le ticket de départ + archiver
